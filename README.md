# SocPublic Bot (API режим)

Бот мониторит VK страницу `smm.studia` и при появлении нового поста автоматически
создаёт задание на SocPublic через официальное API — с нашим текстом, сразу
пополняет баланс и включает задание.

## Что делает

1. Каждую минуту проверяет последний пост в `vk.com/smm.studia`
2. При новом посте вызывает `task_create` (одним запросом):
   - название с хвостом ссылки (напр. `wall426046437_1696`)
   - наш HTML-текст задания (коммент 7+ слов, реакция, репост, лайки)
   - тип `comment`, ручная проверка отчёта
   - случайное количество выполнений 7-14
   - сразу пополняет баланс (количество x 1.3 руб) и включает задание

## Запуск на Railway

Переменные окружения:
- SP_API_ID  - номер API ключа (например 244)
- SP_API_KEY - API ключ
- PYTHONUNBUFFERED=1 - для живых логов

Значения по умолчанию уже вшиты в код, но через переменные удобнее обновлять.

## Преимущества API режима

- Не нужны cookies (не протухают)
- Создание + пополнение + запуск одним запросом
- task_id и баланс возвращаются в ответе

## Примечание про IP

API принимает запросы с IP, указанных в настройках ключа на SocPublic.
Если включён whitelist - добавь туда IP (или диапазон) Railway.
